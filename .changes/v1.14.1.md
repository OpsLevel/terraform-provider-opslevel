## v1.14.1 - [September 25, 2026](https://github.com/OpsLevel/terraform-provider-opslevel/compare/v1.14.0...v1.14.1)
### Fixed
* `opslevel_check_code_issue` now round-trips `max_allowed = 0` in state instead of mapping a returned 0 to null. This removes the perpetual `null -> 0` plan diff and the "Provider produced inconsistent result after apply" error for zero-valued checks. Note: creating or updating a check with `max_allowed = 0` still requires OpsLevel to accept 0 on the `checkCodeIssueCreate`/`checkCodeIssueUpdate` mutations (their generic `checkCreate` mutation already does).
