## v1.13.0 - [August 31, 2026](https://github.com/OpsLevel/terraform-provider-opslevel/compare/v1.12.0...v1.13.0)
### Fixed
* `opslevel_integration_kubernetes` now keeps `etl_definition` state in sync with the API when the block is omitted after creation, and no longer plans changes for semantically equivalent YAML.
### Added
* Add `opslevel_integration_custom` resource for managing Custom Integrations, including their Extract and Transform mapping configuration.
* Add opslevel_campaign_check resource for managing checks copied onto a campaign
* Expose a campaign's checks, including where each was copied from, on the opslevel_campaign data source
### Deprecated
* Deprecate check_ids on opslevel_campaign in favor of the opslevel_campaign_check resource
### Removed
* `etl_definition.extract_definition` and `etl_definition.transform_definition` no longer accept an empty string. Empty values could not round-trip and would clear a stored definition on the API. Omit the whole `etl_definition` block instead to keep OpsLevel's defaults.
